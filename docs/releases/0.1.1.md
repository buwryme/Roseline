# Roséline v0.1.1 is out! 🎉

A release focusing on a Discord RPC rework and font overlaying.

## what's new

- **Font overlaying was reworked:** font overlaying now works via two categories: Font and Monospace font.
  each category replaces its affected `.ttf` files, while the user imports only one.
  language-specific fonts and emoji are intentionally skipped to avoid breakage.
- **Discord RPC was reworked:** it now has three options: 
  a master switch, a switch for show game, and a switch for letting people join you via the presence. 
  the master switch is now off by default, as the setup screen keeps it in an easy sight of reach to 
  instantly enable it. already existing configs are not affected. the Join Game button was also fixed:
  it no longer redirects to a `roblox.com/...` link, but instead uses a redirector from 
  [my website](https://github.com/buwryme/buwryy.net) that opens the `roblox://` handler correctly. 
  why use a redirector through my website? some specific discord clients (on linux mostly) refuse to
  open `roblox://` links for whatever reason, so this guarantees the button always working, everywhere.
- launch log watching now reads the exact `launch-<timestamp>.log` for the current launch instead of 
  scanning old guest logs, and tries its best to stay correct.

## install

```sh
curl -fsSL https://buwryy.net/api/roseline/setup-script | bash
```

non-interactive usage:

```sh
curl -fsSL https://buwryy.net/api/roseline/setup-script | bash -s -- --system --version v0.1.1 --yes
curl -fsSL https://buwryy.net/api/roseline/setup-script | bash -s -- --flatpak --latest --yes
```

**Arch Linux**

```sh
sudo pacman -U roseline-0.1.1-1-x86_64.pkg.tar.zst
```

**Fedora**

```sh
sudo dnf install ./roseline-0.1.1-1.fc*.x86_64.rpm
```

**Debian / Ubuntu**

```sh
sudo apt install ./roseline_0.1.1_amd64.deb
```

**Flatpak**

```sh
flatpak install ./Roseline-0.1.1-x86_64.flatpak
```

**AppImage**

```sh
chmod +x Roseline-0.1.1-x86_64.AppImage
./Roseline-0.1.1-x86_64.AppImage
```

**Nix**

```sh
nix build github:buwryme/Roseline/v0.1.1#roseline
```

The RPM, deb and Arch packages install system-wide. Flatpak grants the Discord
bridges their IPC sockets in the runtime directory. if yours are somewhere
else, Roséline offers the one-time `flatpak override` command on launch.

## known issues

- Roblox's in-client web surfaces do not render yet, **and may even cause a crash**. 
  This includes private server lists. it, unfortunately, isn't an issue Roséline can fix.
- we serve x86_64 only, but manual aarch64 builds are possible.
- The Metal2Vulkan path can be slower than OpenGL in some cases, but notably provides better graphics
