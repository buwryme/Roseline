# Roséline v0.1.4 is out! 🎉

What's new:

- **GameMode toggle**: new toggle in Extras that enables GameMode. runs using D-Bus. 
- **Safer config files**: now warns the user when the config is corrupted and lets them reset or fix it
- **Launches keep working offline**: if the roblox endpoint is unreachable, keep launching the game as normal. this might break joining games, as the client might be outdated.
- **Hardened launches**: force quitting now works properly, logs survive invalid bytes, avatar background no longer warns, and the cookies reseal themselves on a failed launch. THX to @chteau yet again!!
- **Offline runner pick fixed**: when GitHub cannot be reached and no version is cached, the newest installed Rosemary runner is used instead of the oldest.

THX to @chteau for GameMode, and most of the fixes in this release.

**Full Changelog**: https://github.com/buwryme/Roseline/compare/v0.1.3...v0.1.4
