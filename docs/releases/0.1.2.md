# Roséline v0.1.2 is out! 🎉

Big release! Your Roblox session now lives in the login keyring via `libsecret` instead of a plaintext cookie file.

Also new:

- **Custom Rosemary imports**: bring your own Rosemary build
- **Avatar head in Discord RPC**: replace the small image with your avatar's head
- **Old avatar editor background**: swap the avatar editor background with the classic one
- **Close when leaving a game**: quits Roblox when you leave a game, removing the homescreen fully
- **Manual FastFlags overrides**: now allowed!
- **Server location notifications**: see the city and country of the server you just joined.
- **ARM64 builds**: ARM64 builds are now supported, and are done via running Rosemary using muvm. thank you starraepp for this!!

**Full Changelog**: https://github.com/buwryme/Roseline/compare/v0.1.1...v0.1.2

### install:

```sh
curl -fsSL https://buwryy.net/api/roseline/setup-script | bash
```
