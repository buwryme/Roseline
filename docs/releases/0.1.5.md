# Roséline v0.1.5 is out! 🎉

What's new:

- **Custom Rosemary builds stay selected on first launch**: importing a runner before the first launch no longer downloads an official build or switches away from it.
- **The newest runner is now properly fetched on first install**: a stale cached tag can no longer make an older installed Rosemary build be installed.
- **Vulkan detection is more robust**: auto graphics now checks the same ICD paths as the Vulkan loader, including the XDG data dirs, `/run/opengl-driver` on NixOS, and the Flatpak host view.
- **Faster ARM64 packages**: Arch, RPM and deb ARM64 builds now run inside the target distribution's rootfs on an Ubuntu 24.04 ARM64 host

THX to @dfbro for the custom-import report, and to @arcthurr for the runner pick report.

**Full Changelog**: https://github.com/buwryme/Roseline/compare/v0.1.4...v0.1.5

### install:

```sh
curl -fsSL https://buwryy.net/api/roseline/setup-script | bash
```

Have fun!
