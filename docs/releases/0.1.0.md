# Roséline v0.1.0 is out! 🎉

The first release of Roséline!

## What's here so far:

- A first-run setup screen: Pick the GPU and Graphics API, toggle Discord RPC,
  change Rosemary versions, environment variables, and fetch Roblox along with
  the Darwin base.
- Vulkan by default through Metal2Vulkan (thanks to Rosemary!)
- Content overlays for cursors, fonts, skyboxes, sounds and platform textures
- Rosemary runner management
- FastFlags (locked down to Roblox's allowlist)
- Discord Rich Presence with the game cover and an optional Join Game button
- `roblox://` and `roblox-player://` handlers for Play buttons and private
  server links
- packages for Arch, Fedora and Debian/Ubuntu, plus Flatpak, AppImage and Nix
  builds

The client is always the latest production build from Roblox's own endpoint.
There is no Wine or Proton involved. Rosemary runs the macOS build directly.

## Install

Pick the build that matches your system:

**Arch Linux**

```sh
sudo pacman -U roseline-0.1.0-1-x86_64.pkg.tar.zst
```

**Fedora**

```sh
sudo dnf install ./roseline-0.1.0-1.fc*.x86_64.rpm
```

**Debian / Ubuntu**

```sh
sudo apt install ./roseline_0.1.0_amd64.deb
```

**Flatpak**

```sh
flatpak install ./Roseline-0.1.0-x86_64.flatpak
```

**AppImage**

```sh
chmod +x Roseline-0.1.0-x86_64.AppImage
./Roseline-0.1.0-x86_64.AppImage
```

**Nix**

```sh
nix build github:buwryme/Roseline/v0.1.0#roseline
```

The RPM, deb and Arch packages install system-wide. Flatpak grants the Discord
bridges their IPC sockets in the runtime directory; if yours lives somewhere
else, Roséline offers the one-time `flatpak override` command on launch.

## known issues

- Roblox's in-client web surfaces do not render yet. This includes private server lists.
  This, unfortunately, isn't an issue Roséline can fix.
- You can hear other people in voice chat, but microphone input does not work.
  Same as above.
- x86_64 only, but aarch64 builds are possible.
- The Metal2Vulkan path can be slower than OpenGL in some cases
